\begin{itemize}
  \item \textbf{Multi-agent system (LangGraph).} Reduced a recurring B2B operational workflow from $\sim$1 month to $\sim$40 minutes with a production multi-agent system on LangGraph: agents only where the work is open-ended (a ReAct planner with 14 tools), deterministic workflow subgraphs everywhere else, and human-in-the-loop approval gates before any state-changing operation.
