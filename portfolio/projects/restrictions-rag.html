The problem

Construction teams plan each week by clearing constraints upfront: materials, crews, permits, equipment. Planners listed them from memory, so lessons from one site rarely reached the next, and the same blockers kept slowing work down.

How it works

  1. SelectThe planner picks up to 8 activities for the coming week.
  2. RetrieveSemantic search over this project's past constraints, then the same builder's other sites, then a curated base. Metadata filters run before cosine similarity.
  3. SuggestThe model drafts one constraint per activity with type, sector, impact and a due date, plus a two-sentence reason that cites its source.
  4. GuardDeterministic checks drop duplicates and anything outside the project's catalog. If there's no precedent, the suggestion says so.
  5. Review & saveThe planner edits, assigns owners and saves. The AI never assigns people.

Deterministic codeAI modelHuman decision

Key decisions

  • Filter by metadata first, then rank by similarity, so the model only reasons over relevant history.
  • Every suggestion shows where it came from; "no precedent" is stated, not hidden.
  • Metered usage: AI credits per company, logged per project and per user for billing.
