The problem

Urban analysts kept hitting the same wall: points, polygons and administrative units must be aligned to one grid before modeling. Each project rewrote the same rasterization code, with subtle bugs that leaked into findings.

How it works

  1. Define the gridOne Crif object fixes the bounds and cell size.
  2. RasterizePoints are aggregated and polygons rasterized, with explicit overlap rules.
  3. DistributeDasymetric mapping spreads district totals onto the fine grid using prior weights.
  4. FuseWeighted layers combine into hotspot maps.

Key decisions

  • Every primitive has a formal derivation next to the code.
  • Multi-band normalization puts different signals on one scale before fusing.
  • Custom Jupyter widgets and a Docker image, so collaborators reproduce results without environment churn.
